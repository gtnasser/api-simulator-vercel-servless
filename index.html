MétodoOnde os dados vãoExemplo

        
        
            
GETDados são enviados na URL como query string (?chave1=valor1[&chave2=valor2...]). Não tem corpo.GET /api/users?name=John&age=30

            
POSTDados são enviados no corpo da requisição. Usado para criar recursos ou enviar payloads maiores (JSON, formulário, etc.).Body: { "message": "Hello World!" }

            
PUTTambém envia dados no corpo, mas a intenção é substituir ou atualizar completamente um recurso existente.Body: { "id": 1, "status": "Enabled" }

            
PATCHEnvia dados no corpo, mas serve para atualizar parcialmente um recurso.Body: { "name": "name changed to Jack" }

            
DELETENormalmente não tem corpo; identifica o recurso a ser removido pela URL ou query string.DELETE /api/users/123

            
HEADIgual ao GET, mas retorna apenas os headers da resposta, sem corpo.HEAD /api/users

            
OPTIONSUsado para descobrir quais métodos e cabeçalhos são permitidos em um endpoint.OPTIONS /api/users
